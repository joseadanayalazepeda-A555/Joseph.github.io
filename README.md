# Jose Adan Ayala — Portfolio

A single-page personal portfolio for the Founding Class Fellowship application. The site is intentionally lightweight and static: `index.html` plus local image assets. The selected visual artifacts are standardized in English and share a unified Neon iOS27-inspired visual language.

## Evidence structure

The portfolio separates:

- completed work and documented evidence;
- public articulation and reach;
- current research directions and hypotheses.

The distinction is deliberate: current research is not presented as completed findings.

## Before publishing

1. Review each project description and date.
2. Add an external link to the Adam Intelligence V1.0 record only if you want the foundational document to be publicly reviewable.
3. Add any additional public evidence you want to expose, especially older ASK or 3A material.
4. Add the one-minute video link in the fellowship application; it does not need to live on this site.
5. Keep the distinction between historical evidence and current research.

## Fast publishing options

### GitHub Pages
- Create a repository.
- Upload `index.html` and the `assets` folder.
- Enable GitHub Pages in repository settings.
- Use the resulting `github.io` URL in the application.

### Netlify
- Drag the whole folder into Netlify Drop, or connect it through a Git repository.
- Use the generated public URL in the application.

The site has no build step and no external JavaScript dependencies.
